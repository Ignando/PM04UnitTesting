# Mzansi Tech Contractors Payroll

Windows Forms payroll application for SDT621 PM-04 testing and debugging.

## Projects

- `PayrollApp`: WinForms application.
- `PayrollApp.Tests`: MSTest project for unit, integration, validation, retesting, and regression evidence.

## Run

```powershell
dotnet run --project PayrollApp\PayrollApp.csproj
```

## Test

```powershell
dotnet test PayrollApp.Tests\PayrollApp.Tests.csproj
```
